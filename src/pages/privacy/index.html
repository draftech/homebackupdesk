Privacy

This static site does not set analytics cookies.

The Home Backup is HTML, CSS, and a tiny menu script. There is no account system and no first-party analytics in this repository.

thehomebackup.com · updated August 26, 2026

We do not ask you to create a login. We do not run a newsletter form in this codebase. We do not drop a first-party analytics pixel, ad pixel, or session recorder. The pages you read are files. The only script we ship is the small menu and sticky-bar helper in /assets/desk.js.

When you follow an affiliate hop such as /go/jackery, /go/bluetti, /go/anker-solix, or /go/ecoflow, the destination site (Jackery, BLUETTI, Anker SOLIX, EcoFlow, or their network) may set its own cookies so a later purchase can be attributed. Their policies apply after you leave. We cannot see what you buy on those sites.

Hosting (Netlify, or whichever static host is connected later) will process IP addresses in ordinary server logs. That is how the internet serves files. We do not put API keys, network secrets, or click IDs that we do not have into this repo. We do not sell a reader list because we do not keep one.

Fonts load from Google Fonts (Newsreader and Source Sans 3). That request is a third-party connection. If you block it, the site still reads in system serif and sans.

If a custom domain and analytics are added later, this page should be updated before any tracker ships. Until then, assume: we log nothing extra, we sell no data, and we do not run ads.txt. Questions: editorial@thehomebackup.com.

Working brand: The Home Backup. Working host we brand toward: thehomebackup.com. Domain is not purchased from this repository.
