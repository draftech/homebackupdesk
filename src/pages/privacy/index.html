Privacy

This static site does not set analytics cookies.

Home Backup Desk is HTML, CSS, and a tiny menu script. There is no account system and no first-party analytics in this repository.

When you follow an affiliate hop such as /go/jackery, the destination site (Jackery, Bluetti, Anker SOLIX, or their network) may set its own cookies. Their policies apply after you leave.

Hosting (Netlify) will process IP addresses in ordinary server logs. We do not put API keys, network secrets, or click IDs that we do not have into this repo.

If a custom domain and analytics are added later, this page should be updated before any tracker ships. Until then, assume: we log nothing extra, we sell no data, and we do not run ads.txt.
