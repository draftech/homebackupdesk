Buy the machine that matches the load.

Home Backup Desk is a field guide for four products: standby generators, expandable home batteries, portable power stations, and folding solar panels.

We do not cover rooftop solar or Tesla Powerwall. If you need HVAC and a well through a multi-day outage, start with a pad generator. If you need a fridge and Wi-Fi for a night, start with a power station.

Whole-house generators

Automatic standby on propane or natural gas. Install usually costs more than the unit.

Home batteries

Expandable kits that can feed an inlet. Not a Powerwall. Not a solar installer quote.

Portable power stations

Carry-in inverters. Jackery, Bluetti, Anker SOLIX. First buy for fridge and essentials.

Portable solar panels

Folding and briefcase panels that plug into a station. No roof rails.

Outage notes

What a station actually runs

A portable power station can cover a refrigerator, network gear, and a CPAP if you size surge correctly. It will not run central air. For that job see generators.
